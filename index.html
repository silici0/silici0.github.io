// 01. sobre

Sobre mim

Sou Engenheiro de Software com mais de 15 anos de experiência arquitetando aplicações web de alto desempenho. Minha especialização atual é frontend moderno em React, Next.js e TypeScript, com gerenciamento de estado escalável usando Zustand e Context API, e documentação de componentes via Storybook.

Entrego software orientado por qualidade e resiliência — pirâmides de testes robustas com Jest (unitário) e Cypress (E2E) integradas a pipelines de CI/CD modernos. Também atuo em modernização de sistemas legados, migrando monolitos PHP/Python para microsserviços em AWS Lambda e EKS, com IaC em Terraform e Pulumi seguindo o AWS Well-Architected Framework.

Stack principal

  • Frontend: React, Next.js, TypeScript, Zustand, Storybook
  • Testes: Jest, Cypress
  • Cloud/IaC: AWS (EC2, EKS, Lambda, SQS, RDS), Terraform, Pulumi
  • Backend: FastAPI (Python), Laravel (PHP)
  • Observabilidade: ElasticSearch APM
