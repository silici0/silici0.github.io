// 01. sobre

Sobre mim — Engenheiro de Software Full Stack

Sou Engenheiro de Software com mais de 15 anos de experiência arquitetando aplicações web de alto desempenho. Minha especialização atual é frontend moderno em React, Next.js e TypeScript, com gerenciamento de estado escalável usando Zustand e Context API, e documentação de componentes via Storybook.

Entrego software orientado por qualidade e resiliência — pirâmides de testes robustas com Jest (unitário) e Cypress (E2E) integradas a pipelines de CI/CD modernos. Também atuo em modernização de sistemas legados, migrando monolitos PHP/Python para microsserviços em AWS Lambda e EKS, com Infrastructure as Code em Terraform e Pulumi seguindo o AWS Well-Architected Framework.

Ao longo da carreira, contribuí para plataformas que processam milhões de transações, liderou equipes multifuncionais e atuou na definição de arquiteturas cloud-native robustas. Meu foco é construir software que escala, com observabilidade, segurança e custos otimizados desde o primeiro deploy.

Stack principal

  • Frontend: React, Next.js, TypeScript, Zustand, Storybook
  • Testes: Jest, Cypress, Testing Library
  • Cloud/IaC: AWS (EC2, EKS, Lambda, SQS, RDS), Terraform, Pulumi
  • Backend: FastAPI (Python), Laravel (PHP), Node.js
  • Observabilidade: ElasticSearch APM, CloudWatch
  • DevOps: Docker, Kubernetes, GitHub Actions, CI/CD

// 06. perguntas frequentes

FAQ — Perguntas Frequentes

Qual é sua disponibilidade para novos projetos?

Estou aberto a oportunidades full-time (CLT ou PJ) e também a projetos de consultoria de curta duração. Minha preferência é por engajamentos de pelo menos 3 meses para entregar valor consistente, mas avalio projetos menores caso o escopo seja bem definido.

Qual modelo de engajamento você prefere?

Trabalho tanto como membro integrado a um time existente quanto como consultor independente. Para engajamentos de consultoria, prefiro escopo fechado com entregas incrementais e revisões quinzenais. Para posições full-time, me adapto à metodologia da empresa (Scrum, Kanban, Shape Up).

Você trabalha remoto ou presencial?

Trabalho 100% remoto desde 2018, a partir de Itu, SP. Tenho experiência com equipes distribuídas em diferentes fusos horários e uso ferramentas como Slack, Linear, Notion e GitHub Projects para manter comunicação assíncrona eficiente. Estou disponível para encontros presenciais eventuais na região de São Paulo.

Quais tecnologias você domina?

Minha stack principal é React, Next.js e TypeScript no frontend, Python (FastAPI) e PHP (Laravel) no backend, e AWS para infraestrutura cloud. Tenho experiência sólida com Terraform, Pulumi, Docker, Kubernetes, Jest, Cypress e ElasticSearch APM. Aprendo novas ferramentas rapidamente quando o projeto demanda.

Como é seu processo de trabalho?

Começo entendendo o problema de negócio antes de propor soluções técnicas. Priorizo entregas incrementais com feedback contínuo, cobertura de testes desde o início, e documentação que permite onboarding rápido de outros devs. Observabilidade e CI/CD são padrão em tudo que construo.
